Guardar para siempre

Cada app que agregues, edites o borres se guarda en apps.json de tu repositorio de GitHub. Queda para siempre y se ve igual en cualquier computadora o celular. Para eso la página necesita un token de GitHub, que se crea una sola vez:

  1. Abrí crear token en GitHub ↗
  2. Nombre: Lanzadera. Vencimiento: el más largo que te deje.
  3. Repository access → Only select repositories → lanzador.
  4. Permissions → Contents → Read and write.
  5. Tocá Generate token, copialo y pegalo acá abajo.

El token queda guardado solo en este navegador. Los alumnos y visitas ven la Lanzadera en modo lectura. Conectá cada dispositivo donde quieras editar.

Categorías

Cambiá el nombre, el ícono, el color o el orden. Al borrar una categoría, sus apps pasan a «Sin categoría».
